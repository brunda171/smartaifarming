# Student Portfolio Website

A modern, responsive personal portfolio website designed for students.

## How to Run
Simply open the `index.html` file in your web browser.

## Features
- **Hero Section**: Animated introduction.
- **About & Education**: Timeline of your academic journey.
- **Projects**: Grid display of your work.
- **Contact**: Simple contact form layout.
- **Responsive**: Works on mobile and desktop.
- **Dark Mode**: Sleek dark theme with glassmorphism effects.

## Customization
Edit `index.html` to update your name, education details, and projects.
Customize colors in `styles.css` (root variables).
